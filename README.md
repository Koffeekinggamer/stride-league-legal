# ZarSeb Enterprises app support

Privacy, support, account deletion, and security pages for ZarSeb Enterprises apps.

Published at https://koffeekinggamer.github.io/stride-league-legal/

Stride League stays at the original paths: `/privacy/`, `/terms/`, and `/delete-account/`. Walkie is under `/walkie/`.

To add an app, copy `_template/` and follow the README in that folder. Jekyll does not publish a folder whose name starts with an underscore.
